1. MJ Variant Finder とは

MJ Variant Finder（異体字検索）は、戸籍や住民基本台帳などで使われる漢字の字形を整理した「文字情報基盤（MJ文字情報一覧表）」と、その約6万の字形を収録した「IPAmj明朝」の異体字（IVS）を、ブラウザだけで検索・比較・コピー・画像書き出しできる静的Webツールです。

PC やスマートフォンに特別なフォントをインストールしていなくても、必要な分だけ読み込む Web フォントを使って、画面上で異体字を表示・見比べることができます。インストール不要、完全無料で利用できます。

主な特徴
  • インストール不要: ブラウザを開くだけで約6万の字形を表示
  • 多彩な探し方: 漢字、読み（ひらがな）、字の通称（「はしごだか」「たてにし」など）、手書き、スクリーンショットからの画像検索
  • 文字の違いを可視化: 標準字形とどこが違うかを赤・青のハイライトで色分け表示
  • デザイン・印刷に直結: 背景透明 PNG の画像コピー、ベクター SVG の書き出しに対応

2. IVS（異体字セレクタ）とは

人名や地名には、同じ「ワタナベ」「サイトウ」でも、しんにょうの点の数や部首の払いの長さ、線の繋がり方が異なる膨大な「異体字」が存在します。

Unicode と「同じ文字」のジレンマ

世界共通の文字コード規格である Unicode では、文字の意味や起源が同じ漢字には、原則としてひとつのコードポイント（番号）を割り当てて統合しました（例: 一般的な「辺」は U+8FBA）。

しかし、日本の戸籍、住民基本台帳、法務省の登記などの公的業務、あるいは個人の名義表記では、「1点しんにょう」と「2点しんにょう」、「自の横棒が突き抜ける・抜けない」などの細かな字形の差異を厳格に区別する必要があります。

点（丶）が1つ。現代の一般的な当用漢字・常用漢字の字形。
辺󠄂
2点しんにょう
点（冫）が2つ。伝統的な旧字体や人名で重視される字形。

IVS（Ideographic Variation Sequence）の仕組み

かつては文字コードにない異体字を「外字（ガイジ）」として各社バラバラに登録していたため、メールで送ると文字化けしたり、別のパソコンで開くと消えてしまう問題がありました。

この問題を国際標準で解決するために策定された仕組みが IVS（異体字シーケンス） です。

IVS では、通常の漢字（基底文字）の後ろに、目に見えない特殊な補助コードである「異体字セレクタ（Variation Selector: VS17〜VS256、U+E0100〜U+E01EF）」を1文字連結します。

文字情報基盤（MJ文字）と IPAmj明朝

情報処理推進機構（IPA）は、戸籍や住民基本台帳などの行政で使われる約6万の漢字の字形を整理し、「MJ文字情報一覧表」としてまとめました（現在は一般社団法人 文字情報技術促進協議会が公開・維持しています）。そのすべての字形を収録し、無償で公開されているフォントが「IPAmj明朝」です。

3. コピーしても化ける理由

「MJ Variant Finder で見つけた異体字をコピーしたのに、別のアプリやSNSに貼り付けたら普通の文字に戻ってしまった…」という経験はありませんか？

これは不具合ではなく、デジタルフォントとアプリケーションが IVS を処理する仕組みに原因があります。

原因 1: 貼り付け先で選んでいるフォントが IVS に非対応

IVS は「基底文字 ＋ 異体字セレクタ」という2文字の組み合わせを、フォント内のプログラム（OpenType の cmap format 14 テーブル）が解釈して、1つの特殊な絵柄（グリフ）にすり替えて画面に描画します。

IVS には、字形を登録した団体ごとの「登録集（コレクション）」があります。MJ文字情報一覧表の字形は Moji_Joho という登録集です。パソコンに最初から入っているフォントの中には IVS に対応したものもありますが、対応しているのは別の登録集で、Moji_Joho の IVS にはほとんど対応していません。

フォントがその IVS に対応していない場合、セレクタは無視され、基底文字（通常の漢字）の形で表示されます。その結果、「コピーしたはずの異体字が、普通の字に戻ってしまった」ように見えます。

原因 2: アプリケーションがセレクタを削除または分断する

アプリや Web サービスによっては、貼り付けや保存のときに、目に見えない文字である異体字セレクタ（U+E0100〜）を取り除いてしまうことがあります。この場合は、どのフォントを選んでも通常の字形になります。

また、古いテキストエディタでは、不可視のセレクタを解釈できず、文字の後ろに「□（豆腐）」や「？」、謎の空白が表示されることがあります。

どう対策すればいいのか？

やりたいこと 推奨される方法 ポイント
Canva や SNS で使いたい 「画像でコピー」または「SVG保存」 文字ではなく画像・ベクター素材として貼り付ければ、相手の環境やフォントに関係なく、同じ形で表示されます。
Word / Excel で使いたい フォントに「IPAmj明朝」を指定 PC に IPAmj明朝をインストールし、貼り付けた文字のフォントを「IPAmj明朝」に変更します。相手に送る際は PDF 化が安全です。
Illustrator / 印刷物で使いたい 「SVGで保存」して配置 ベクターパスとして配置されるため、拡大しても劣化せず、アウトライン化の手間も不要です。

4. Canva やデザインツールで異体字を使う方法

Canva などのグラフィックツールで異体字を扱うベストプラクティスを、手順付きで解説します。

方法 A: 複数文字をまとめて連結書き出し・貼り付け（おすすめ！新機能）

「渡邉」「齊藤」など、複数文字の苗字・単語をデザインに配置する場合、1文字ずつコピーして位置合わせをするのは大変です。MJ Variant Finder では、複数文字を横書き・縦書きで連結した1枚の画像（透明PNG・最大2048px）またはベクターSVGとして直接書き出せます。

1

複数文字を入力して検索

トップページの検索欄に目的の単語（例: 「渡辺」「さいとう」）を入力して検索します。

2

「📷 連結書き出し・比較」ボタンを押す

検索結果ヘッダーの「📷 連結書き出し・比較」をクリックすると、検索された文字が自動的に比較リストにセットされ、書き出しパネルが開きます（字形カードの「比較」ボタンを押して好きな字形を組み合わせることも可能です）。

3

向き（横書き／縦書き）と解像度を選択

ダイアログ下部の連結書き出しパネルで、配置したい向き（横書き・縦書き）と解像度（標準512px / 高解像度1024px / 超高解像度2048px）を選びます。

4

「📋 画像をコピー」を押して Canva に貼り付け

「📋 画像をコピー」をクリックし、Canva の編集画面で Ctrl + V（Mac は Cmd + V）を押すと、背景透明の整列された文字列画像が一発で貼り付けられます。

方法 B: 単一文字を「画像でコピー」してそのまま貼り付け

1文字だけを使いたい場合は、カード詳細からわずか数秒で Canva 上に配置できます。

1

目的の字形カードの詳細を開く

一覧から使いたい字形のカードをクリックすると、詳細ダイアログが開きます。

2

「画像でコピー」ボタンを押す

エクスポート欄の「画像でコピー」をクリックします。クリップボードに、背景が透明な PNG（1024×1024 ピクセル）がコピーされます。

3

Canva のデザイン画面で貼り付け（Ctrl + V）

Canva の編集画面を開き、キーボードの Ctrl + V（Mac は Cmd + V）を押すと、背景が透明な画像として貼り付けられます。

なぜ「画像でコピー」が優れているのか？
  • 背景が透明（アルファチャンネル）: 写真やグラデーション、カラー背景の上に重ねても背景を邪魔しません。
  • ベースライン・文字間隔が正確: 複数文字の連結コピーを使えば、手動で文字間を詰める苦労が不要です。
  • フォントの有無に左右されない: Canva 側に IPAmj明朝が無くても、ツールで表示した字形のまま使えます。

方法 C: 「SVGで保存」してベクター素材として利用（商業印刷・拡大向け）

看板、大型ポスター、プロのDTPワークフローなど、拡大しても劣化しないベクターデータが必要な場合は、SVG 形式でのエクスポートが最適です（単一文字・複数文字連結のどちらも SVG 保存に対応しています）。

  1. 詳細ダイアログの「SVGで保存」、または連結パネルの「📐 SVGで保存」をクリックします。
  2. フォントファイルではなく、文字の輪郭線（アウトラインパス）そのものが SVG 化されています。
  3. Canva の「アップロード」から SVG ファイルを読み込むと、拡大・縮小しても劣化しないベクター素材として使えます。
  4. Adobe Illustrator などのベクター編集ソフトでも直接パスデータとして開けます。

方法 D: Word・Excel・PowerPoint で文字として使いたい場合

  1. パソコンに公式の IPAmj明朝フォント をダウンロード・インストールします。
  2. MJ Variant Finder で字形カードの「コピー」ボタンを押して、IVS 付きの文字をクリップボードにコピーします。
  3. Word や Excel に貼り付け、貼り付けた文字のフォントを「IPAmj明朝」に指定します。
  4. 相手にファイルを送る場合の注意点: 相手のパソコンに IPAmj明朝が入っていないと文字の形が変わってしまうため、完成した文書は「PDF 形式で保存」して配布するか、文字の代わりに「画像でコピー」を貼り付けることを強く推奨します。

5. ツールの便利な使い方

MJ Variant Finder には、日常の業務やデザイン作業を快適にする多彩な機能が備わっています。

入力できない字も探せる 5 つの検索方法

  • 1. 漢字・単語検索: 「渡辺」のように複数文字を一気に入力すると、文字ごとのタブに分解され、関連する異体字（邉・邊）まで自動で一覧表示されます。
  • 2. 読み検索（ひらがな）: 「さいとう」と入れると、姓・地名の辞書と照合し、「斉藤」「斎藤」「齊藤」「齋藤」などの代表的な表記候補がサジェストされます。
  • 3. 字の通称・呼び名検索: 現場や日常でよく使われる通称で検索できます。
    • 代表的な異体字: 「はしごだか（髙）」「つちよし（𠮷）」「まゆはま（濵）」「まのれい（令󠄂）」「てんつきつか（塚）」
    • 字形の判別: 「ひのかつ（葛：下がヒ）」「においかつ / ちのかつ（葛：下が匂）」「つきぬけつの（角）」「たてにし（西）」
    • しんにょうの点数: 「いってんしんにょうのたつ（達）」「にてんしんにょうのみち（道）」「いってんしんにょうのひ（樋）」
    • へん・つくりの形: 「しめすへんのかみ（神）」「しめすへんのふく（福）」「てんつきいのしし（猪）」「まるやなぎ（栁）」「じゅうじゅうくわ（桒）」「えだじょう（條）」
    • 品字様（3つ重ね漢字）: 「みつくるま（轟）」「みつうま（驫）」「みつむし（蟲）」「みつき（森）」「みつくち（品）」「みつけ（毳）」
    • 部首名＋の＋読み: 「やまへんのさき（﨑）」「いしへんのさき（碕）」「ちからのこう（効）」など約140種類の部首名に対応
  • 4. 手書き認識で探す: 読み方が分からない字は、検索欄下の「手書きで探す」をクリックし、マウスやスマホのタッチで文字を描けば、似ている漢字を候補として出します。
  • 5. スクリーンショットから探す: 画面のスクリーンショットを貼り付け（またはドラッグ＆ドロップし）、1文字を囲むと、似ている MJ 字形を候補として出します。明朝体で表示された文字が得意で、写真の手書き文字や小さな文字は苦手です。

検索履歴とお気に入り（ピン留め）で素早く呼び出す

何度も調べる漢字や、定期的なデザイン業務で使う異体字をスムーズに再利用できます。

  • 検索履歴: 検索した文字が直近10件まで検索バーの下に自動でチップ表示されます。クリック1つですぐに再検索できます。
  • お気に入り（ピン留め）: カード詳細ダイアログの「☆ お気に入り」ボタンを押すと、最大20件までピン留めできます。よく使う異体字を登録しておけば、検索ワードを打ち込む手間が省けます。
  • 完全ローカル保存の安心設計: 履歴やお気に入りのデータはお使いのブラウザの localStorage にのみ保存されます。外部サーバーに送信されることは一切ないため、プライベートな業務でも安心してお使いいただけます。

字形の比較と連結書き出し（並べる・重ねる・一括画像化）

「渡辺」の「辺」「邉」「邊」のように、複数の字形を横に並べて見比べたり、先頭の2文字を重ね合わせて微細な画の違いをカラーで確認できます。

比較リストに2文字以上の字形が入ると、下部に「連結書き出し」パネルが表示されます。比較して選んだ複数の異体字を、そのまま横書き・縦書きの高解像度PNGやSVGとして一括書き出し・コピーできます。

混同しやすい字・異構字の相互リンクと表記候補サジェスト

文字コード（UCS）が分かれている異構字（島・嶋・嶌、柳・栁、峰・峯など）や、形が酷似していて誤読・混同されやすい漢字（柿と杮、荻と萩、粟と栗など）を迷わず見つけられるアシスト機能です。

  • 異構字・代表的異体字の相互リンク: 「島」を調べると「嶋」「嶌」のリンクが表示され、「嶋」を調べても「島」「嶌」へ1クリックでジャンプできます。「➕ 並べて比較」ボタンを押せば、全バリエーションを即座に比較トレイに並べて確認できます。
  • 類似字・誤認頻出字の注意喚起: 果物の「柿（木＋市 5画）」を引くと、「こけら落とし」の「杮（木＋巿 4画縦貫通）」への注意喚起と見分け方メモが表示されます。ワンクリックで両方の字形を比較・重ね合わせして微細な違いを検証できます。
  • 単語検索時の表記候補サジェスト: 「中島」と検索すると「中嶋」「中嶌」、「柳田」と検索すると「栁田」、「山崎」なら「山﨑」「山嵜」といった実在する別の表記候補チップがヘッダーに自動提示されます。

違いを色で表示（グリフ差分ハイライト）

「標準の字とどこが違うのかパッと見ではわからない…」という時に役立つのが「違いを色で表示」ボタンです。

IVS を付けない通常の字形と重ね合わせ、この字形にだけある部分を赤、通常の字形にだけある部分を青で示し、共通の部分は薄く表示します。通常の字形と同じ字形には「IVSなしと同じ」の印が付きます。

ゴシック体判定バッジ（○ / △ / ×）

「明朝体ではなくゴシック体でデザインしたいが、この異体字はゴシック体でも使えるのか？」を判別できるバッジです。

  • ゴシック○: 文字コードだけで表せる字形で、判定に使ったゴシック体（Noto Sans JP）にもその字があります。ゴシック体でもその字として表示できます（字のデザインはゴシック体のものになります）。
  • ゴシック△: 文字コードだけで表せる字形ですが、ゴシック体のフォントにその字が無いことがあります。
  • ゴシック×: IVS でしか区別できない字形です。ゴシック体では通常の字形で表示されるので、明朝体（IPAmj明朝）で使うか、画像で使ってください。

6. よくある質問（FAQ）

Q. 苗字など複数文字をまとめて Canva や Illustrator に持ち込めますか？

はい、対応しています。

「渡辺」などの複数文字で検索した際、ヘッダーに表示される「📷 連結書き出し・比較」ボタンをクリックすると、検索結果の文字が比較トレイにセットされ、連結書き出しパネルが開きます。

横書きまたは縦書き、解像度（標準512px / 高解像度1024px / 超高解像度2048px）を選んで「📋 画像をコピー」を押せば、Canva やデザインツールにきれいに整列した1枚の画像として貼り付けられます。1文字ずつ行間や文字間を手動で詰める手間がありません。

Q. 書き出した画像や SVG は商用利用できますか？

はい、商用利用を含め自由にお使いいただけます。

本ツールが生成する PNG・SVG 画像は、IPAmj明朝の派生フォントから描画されています。IPAフォントライセンス第2条に基づき、フォントを使用して作成されたデジタル成果物（画像・ベクター・印刷物など）は、営利・非営利を問わず自由に利用・配布できます。

ただし、字形が正しいかどうかは保証しません。公的な書類などに使う場合は、必ず確認してください。

Q. スマートフォンでも使えますか？

はい、スマートフォン・タブレットのブラウザでも使えます。

スマホの狭い画面に最適化したレイアウトを採用しており、タッチ操作での手書き入力や、スクリーンショットの画像検索もそのまま行えます。「画像でコピー」はブラウザによって使えないことがあるので、その場合は「PNGで保存」を使ってください。

Q. ツールを使うためにフォントをインストールする必要はありますか？

インストールは一切不要です。

本ツールは、必要な字形の分だけを読み込む Web フォント（WOFF2）を自動で使うため、IPAmj明朝が入っていないパソコンやスマートフォンでも、ツールの画面では字形を見分けられます。

Q. Webサイトの制作で異体字を表示するにはどうすればいいですか？

HTML に直接 IVS 文字を記述するか、数値文字参照（例: &#x9089;&#xE010F;）を使用し、CSS の font-family に IVS 対応フォント（または本ツールのように subset された Web フォント）を指定します。閲覧者の環境に左右されずに表示したい場合は、本ツールの「SVGで保存」で書き出した SVG を埋め込む方法もあります。

Q. 字形や文字コードが正しいか確かめるには？

公的機関やデータの提供元が公開している、次の検索で確かめてください（本ツールはこれらの検索システムとは無関係です）。

  • 戸籍統一文字情報（法務省）: 戸籍で使う字を、読み・画数・部首・文字コード・戸籍統一文字番号で検索できます。
  • 文字情報基盤検索システム（文字情報技術促進協議会）: MJ文字情報一覧表の字形を検索できます。

戸籍や住民票、公的な申請に使う字は、提出先の窓口にも確認してください。
