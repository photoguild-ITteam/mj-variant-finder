1. MJ Variant Finder とは

MJ Variant Finder（異体字検索）は、日本の公的文字規格である「文字情報基盤（MJ文字情報一覧表）」と、その約6万文字を収録した「IPAmj明朝」フォントの異体字（IVS）を、ブラウザだけで検索・比較・コピー・画像書き出しできる静的Webツールです。

PC やスマートフォンに特別なフォントをインストールしていなくても、独自の分割Webフォント技術により、画面上で正確な異体字を表示・見比べることができます。インストール不要、完全無料で利用できます。

主な特徴
  • インストール不要: ブラウザを開くだけで約6万字の異体字を正確にレンダリング
  • 多彩な探し方: 漢字、読み（ひらがな）、字の通称（「はしごだか」「たてにし」など）、手書き認識、写真やスクショからの画像検索
  • 文字の違いを可視化: 標準字形とどこが違うかを赤・青のハイライトで色分け表示
  • デザイン・印刷に直結: 背景透明 PNG の画像コピー、ベクター SVG の書き出しに対応

2. IVS（異体字セレクタ）とは

人名や地名には、同じ「ワタナベ」「サイトウ」でも、しんにょうの点の数や部首の払いの長さ、線の繋がり方が異なる膨大な「異体字」が存在します。

Unicode と「同じ文字」のジレンマ

世界共通の文字コード規格である Unicode では、文字の意味や起源が同じ漢字には、原則としてひとつのコードポイント（番号）を割り当てて統合しました（例: 一般的な「辺」は U+8FBA）。

しかし、日本の戸籍、住民基本台帳、法務省の登記などの公的業務、あるいは個人の名義表記では、「1点しんにょう」と「2点しんにょう」、「自の横棒が突き抜ける・抜けない」などの細かな字形の差異を厳格に区別する必要があります。

辺󠄁
1点しんにょう
点（丶）が1つ。現代の一般的な当用漢字・常用漢字の字形。
辺󠄂
2点しんにょう
点（冫）が2つ。伝統的な旧字体や人名で重視される字形。

IVS（Ideographic Variation Sequence）の仕組み

かつては文字コードにない異体字を「外字（ガイジ）」として各社バラバラに登録していたため、メールで送ると文字化けしたり、別のパソコンで開くと消えてしまう問題がありました。

この問題を国際標準で解決するために策定された仕組みが IVS（異体字シーケンス） です。

IVS では、通常の漢字（基底文字）の後ろに、目に見えない特殊な補助コードである「異体字セレクタ（Variation Selector: VS17〜VS256、U+E0100〜U+E01EF）」を1文字連結します。

辺󠄂（2点しんにょう） U+8FBA（辺） U+E0102（VS19） MJ025759
邉󠄏（渡邉の代表字形） U+9089（邉） U+E010F（VS32） MJ026190

文字情報基盤（MJ文字）と IPAmj明朝

日本政府（経済産業省・IPA等）は、自治体や行政機関で使われる約6万文字に及ぶ漢字の字形を網羅・整理し、「MJ文字情報一覧表」として公開しました。そして、その約6万文字すべての異体字を正しく画面に表示・印刷できるように無償提供されている公式フォントが「IPAmj明朝」です。

3. コピーしても化ける理由

「MJ Variant Finder で見つけた異体字をコピーしたのに、別のアプリやSNSに貼り付けたら普通の文字に戻ってしまった…」という経験はありませんか？

これは不具合ではなく、デジタルフォントとアプリケーションが IVS を処理する仕組みに原因があります。

原因 1: 貼り付け先で選んでいるフォントが IVS に非対応

IVS は「基底文字 ＋ 異体字セレクタ」という2文字の組み合わせを、フォント内のプログラム（OpenType の cmap format 14 テーブル）が解釈して、1つの特殊な絵柄（グリフ）にすり替えて画面に描画します。

Windows や Mac に最初から入っている一般的なフォント（MS明朝、游明朝、メイリオ、ヒラギノ通常版など）には、数千〜1万字程度の字形しか収録されておらず、すべての IVS 異体字の絵柄を持っているわけではありません。

フォント内にその IVS の字形が存在しない場合、フォントはセレクタ部分を単に無視し、基底文字（通常の漢字）の形だけで描画します。その結果、「コピーしたはずの異体字が、普通の字に戻ってしまった」ように見えます。

原因 2: アプリケーションがセレクタを削除または分断する

Twitter（X）、Instagram、LINE、一部のブログや入力フォーム、デザインツール（Canva等）では、セキュリティ上の理由やシステム設計により、見慣れない不可視コード（U+E0100〜）を「制御文字」「不正な入力」と判定して、貼り付けた瞬間に自動的に削除（サニタイズ）してしまうことがあります。

また、古いテキストエディタでは、不可視のセレクタを解釈できず、文字の後ろに「□（豆腐）」や「？」、謎の空白が表示されることがあります。

どう対策すればいいのか？

やりたいこと 推奨される方法 ポイント
Canva や SNS で使いたい 「画像でコピー」または「SVG保存」 文字テキストではなく、画像・ベクター素材として貼り付ければ、相手の環境に関わらず絶対に形が崩れません。
Word / Excel で使いたい フォントに「IPAmj明朝」を指定 PC に IPAmj明朝をインストールし、貼り付けた文字のフォントを「IPAmj明朝」に変更します。相手に送る際は PDF 化が安全です。
Illustrator / 印刷物で使いたい 「SVGで保存」して配置 ベクターパスとして配置されるため、拡大しても劣化せず、アウトライン化の手間も不要です。

4. Canva やデザインツールで異体字を使う方法

Canva などのグラフィックツールで異体字を扱うベストプラクティスを、手順付きで解説します。

方法 A: 「画像でコピー」してそのまま貼り付け（最短・おすすめ！）

MJ Variant Finder の最大の強みである「画像でコピー」機能を使えば、わずか数秒で Canva 上に正確な異体字を配置できます。

1

MJ Variant Finder で文字を検索

トップページの検索欄に目的の文字（例: 「渡辺」「さいとう」「はしごだか」）を入力して検索します。

2

目的の字形カードの詳細を開く

一覧から使いたい字形のカードをクリックすると、詳細ダイアログが開きます。

3

「画像でコピー」ボタンを押す

エクスポート欄の「画像でコピー」をクリックします。クリップボードに、1024×1024ピクセルの超高解像度・背景透明PNG がコピーされます。

4

Canva のデザイン画面で貼り付け（Ctrl + V）

Canva の編集画面を開き、キーボードの Ctrl + V（Mac は Cmd + V）を押すだけ！キャンバス上に異体字が透過画像として瞬時に配置されます。

なぜ「画像でコピー」が優れているのか？
  • 背景が透明（アルファチャンネル）: 写真やグラデーション、カラー背景の上に重ねても背景を邪魔しません。
  • 1024px の高解像度: ポスターやチラシなどの印刷用途に引き伸ばしても、文字の輪郭がボケずにくっきり美しく印刷できます。
  • フォントの有無に左右されない: Canva 側に IPAmj明朝フォントがなくても、100% 正確な字形がそのまま使えます。

方法 B: 「SVGで保存」してベクター素材として利用（商業印刷・拡大向け）

看板、大型ポスター、プロのDTPワークフローなど、無限に拡大しても一切劣化しないベクターデータが必要な場合は、SVG 形式でのエクスポートが最適です。

  1. 詳細ダイアログの「SVGで保存」をクリックします（例: MJ026190.svg がダウンロードされます）。
  2. フォントファイルではなく、文字の輪郭線（アウトラインパス）そのものが SVG 化されています。
  3. Canva の「アップロード」メニューに SVG ファイルをドラッグ＆ドロップすると、ベクターイラスト素材として自由に着色・拡大・縮小ができます。
  4. Adobe Illustrator や InDesign でも、そのまま配置して編集できます。

方法 C: Word・Excel・PowerPoint で文字として使いたい場合

  1. パソコンに公式の IPAmj明朝フォント をダウンロード・インストールします。
  2. MJ Variant Finder で「コピー（IVS文字）」ボタンを押して、クリップボードに文字をコピーします。
  3. Word や Excel に貼り付け、貼り付けた文字のフォントを「IPAmj明朝」に指定します。
  4. 相手にファイルを送る場合の注意点: 相手のパソコンに IPAmj明朝が入っていないと文字の形が変わってしまうため、完成した文書は「PDF 形式で保存」して配布するか、文字の代わりに「画像でコピー」を貼り付けることを強く推奨します。

5. ツールの便利な使い方

MJ Variant Finder には、日常の業務やデザイン作業を快適にする多彩な機能が備わっています。

入力できない字も探せる 5 つの検索方法

  • 1. 漢字・単語検索: 「渡辺」のように複数文字を一気に入力すると、文字ごとのタブに分解され、関連する異体字（邉・邊）まで自動で一覧表示されます。
  • 2. 読み検索（ひらがな）: 「さいとう」と入れると、姓・地名の辞書と照合し、「斉藤」「斎藤」「齊藤」「齋藤」などの代表的な表記候補がサジェストされます。
  • 3. 字の通称・呼び名検索: 業界や現場でよく使われる「はしごだか」「たてにし」「たつさき」「やまへんのさき（部首名＋の＋読み）」などの通称で検索できます。
  • 4. 手書き認識で探す: 読み方が分からない字は、検索欄下の「手書きで探す」をクリックし、マウスやスマホのタッチで文字を描けば、類似する漢字を瞬時に推定します。
  • 5. 写真やスクショから探す: 名刺や書類の写真を撮って貼り付ける（またはドラッグ＆ドロップする）だけで、画像処理アルゴリズムが合致するMJ字形を特定します。

違いを色で表示（グリフ差分ハイライト）

「標準の字とどこが違うのかパッと見ではわからない…」という時に役立つのが「違いを色で表示」ボタンです。

IVS を付けない通常の字形と重ね合わせ、この異体字にだけ存在する線を「赤」、通常の字形にある線を「青」でハイライトします。線の長さの違いや点の位置の差異が一瞬で見分けられます。

ゴシック体判定バッジ（○ / △ / ×）

「明朝体ではなくゴシック体でデザインしたいが、この異体字はゴシック体でも使えるのか？」を判別できるバッジです。

  • ゴシック○: 代表的なゴシック体（Noto Sans JP や BIZ UDゴシック）にも同じ字形が存在し、ゴシック体でも安全に使えます。
  • ゴシック△: 一部のゴシック体フォントで字形が欠けている可能性があります。
  • ゴシック×: IVS でのみ区別される字形で、一般的なゴシック体では通常の字形に戻ってしまいます（明朝体の使用、または画像での利用を推奨）。

6. よくある質問（FAQ）

Q. 書き出した画像や SVG は商用利用できますか？

はい、商用利用を含め自由にお使いいただけます。

本ツールが生成する PNG・SVG 画像は、IPAmj明朝の派生フォントから描画されています。IPAフォントライセンス第2条に基づき、フォントを使用して作成されたデジタル成果物（画像・ベクター・印刷物など）は、営利・非営利を問わず自由に利用・配布できます。

Q. スマートフォンでも使えますか？

はい、スマートフォン・タブレットのブラウザでも完全動作します。

スマホの狭い画面に最適化したレイアウトを採用しており、タッチ操作での手書き入力や、スマホで撮影したスクリーンショットの画像検索もそのまま行えます。

Q. ツールを使うためにフォントをインストールする必要はありますか？

インストールは一切不要です。

本ツールは必要な字形だけをその場で分割ダウンロードする Web フォント（WOFF2）を自動で読み込むため、フォントが一切入っていないパソコンやスマートフォンでも正確な字形が表示されます。

Q. Webサイトの制作で異体字を表示するにはどうすればいいですか？

HTML に直接 IVS 文字を記述するか、数値文字参照（例: &#x9089;&#xE010F;）を使用し、CSS の font-family に IVS 対応フォント（または本ツールのように subset された Web フォント）を指定します。閲覧者の環境に依存せず100%確実に表示させたい場合は、本ツールの「SVGで保存」を活用してインライン SVG として埋め込む方法も非常に効果的です。

Q. MJ Variant Finder は公的機関の公式ツールですか？
