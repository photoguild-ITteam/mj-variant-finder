# 互換の方針と版の付け方

1.0.0 以降、ここに書いたものは**互換を保って変えます**。互換を崩す変更をするときは、メジャー版（1.x → 2.0）を上げ、CHANGELOG に「互換を崩す変更」として書きます。0.x の間は、マイナー版でも崩すことがあります。

版の番号は [セマンティック バージョニング](https://semver.org/lang/ja/) に従います（`MAJOR.MINOR.PATCH`）。

## 互換を守るもの

### 1. URL（共有したリンク・ブックマーク）

- 検索語は URL の `#q=` に入れます。検索語は `encodeURIComponent` で符号化します（例: `#q=%E6%B8%A1%E8%BE%BA`）。
- `+` は、空白ではなく `+` そのものとして読みます（`#q=U+8FBB` は「U+8FBB」）。
- `#q=` 以外の項目（`#q=…&x=…` の `x`）は無視します。今後、項目を足すことはありますが、`#q=` だけの URL は今と同じように開けるようにします。
- 次の書き方の検索語は、今と同じ意味で受け付けます。
  - 字・単語（IVS 付きも可）
  - 読み（ひらがな・カタカナ）
  - MJ文字図形名（`MJ026190`）
  - コード（`U+8FBB`・`9089_E010F`・`&#x9089;` など）

  ただし、**検索結果の中身**（どの字形が出るか、並び順、候補）は、データと検索の改良に応じて変わります。

### 2. ブラウザに保存するデータ

保存先は、置いたサイトの localStorage です。キーはすべて `mjv_` で始めます（同じ origin の別のページとぶつからないように）。

| キー | 中身 | 値の形 |
|---|---|---|
| `mjv_history` | 検索履歴（新しい順、最大 10 件） | 文字列の配列（JSON） |
| `mjv_favorites` | お気に入り（最大 20 件） | 文字列の配列（JSON） |
| `mjv_theme` | テーマ | `light` または `dark` |
| `mjv_glyph_diff` | 「違いを色で表示」 | `on` または `off` |

- 上の形で保存した値は、今後の版でも読めるようにします。
- **形やキーを変えるときは、古いキー・古い形から読み移します。** 読み移しの処理は `src/js/storage.js` に置き、テストを付けます。
- **古いキーは消しません。** 同じ origin の別のページが、同じ名前のキーを使っているかもしれないためです。
- 0.6 までのキー（`theme`・`glyph-diff`）は、`mjv_theme`・`mjv_glyph_diff` へ自動で読み移します。
- 項目を足すことはあります（キーは `mjv_` 付きにします）。

### 3. コピー・書き出し

| 操作 | 守ること |
|---|---|
| 文字のコピー | IVS 付きの文字列・MJ文字図形名・`U+` 表記・HTML の数値文字参照・JavaScript のエスケープ、の各形式を選べること |
| 字形の画像（1字） | ファイル名は `MJ文字図形名.png`・`MJ文字図形名.svg`（例: `MJ026190.png`） |
| 字形の画像（複数字の連結） | ファイル名は `字（異体字セレクタを除く）_MJ文字図形名を_でつないだもの`（例: `邉辺_MJ026190_MJ025758.png`） |
| PNG・SVG の既定 | 背景は透明、文字は黒。PNG は 1em あたり 1024px（連結の書き出しは画面で 512・1024・2048px を選べる）。SVG はアウトライン（パス） |

- 選べる項目（色・余白など）を足すことはありますが、**何も選ばなければ今と同じ形**で書き出します。
- 字形そのものは IPAmj明朝 Ver.006.01 によります。フォントの版を上げたときは、字形が変わることがあります（CHANGELOG の「データ」に書きます）。

### 4. 自分のサイトに置くための条件

- 次のものをまとめて静的なサーバーに置けば動くこと。
  - `index.html`・`guide.html`
  - `src/`
  - `LICENSE`・`LICENSES.md`・`licenses/`

  サーバーでの処理・ビルド・外部の CDN は要りません。
- `src/js/config.js` の設定項目（`sessionWatch` の `message`・`loginUrl`・`loginLabel`）は、名前と意味を保ちます。
- 必要なことの一覧（ライセンス）は README の「[使い方ごとに必要なこと](../README.md#使い方ごとに必要なこと)」のとおりです。条件を増やすことは、互換を崩す変更として扱います。

## 互換を守らないもの（内部の仕組み）

次のものは、予告なく変えることがあります。頼る場合は、版を固定してください。

- `src/data/` の JSON・`image-index.bin` の形とファイルの分け方（性能やデータの改良のために変える。#49 では書き方を変えた）
- `src/js/` のモジュール・関数の名前と引数、`src/` の中のファイル名（`src/js/config.js` を除く）
- 画面の HTML の構造・CSS のクラス名・見た目
- 検索結果・手書きと画像の候補の中身と並び順
- 開発用のスクリプト（`scripts/`）・テスト・`npm` の scripts

## 版の付け方

| 変更 | 上げる版 | 例 |
|---|---|---|
| 上の「互換を守るもの」を崩す | **MAJOR** | 保存の形を変えて古い値を読めなくする、`#q=` の形を変える、書き出すファイル名を変える、置くのに必要なファイルを増やす |
| 機能の追加、選べる項目の追加、画面の変更 | MINOR | 書き出しの色を選べるようにする、検索の候補を出す |
| 元データの版の更新 | MINOR | MJ文字情報一覧表・IVD・Unihan・KanjiVG・人名辞書の入力の版を上げる。IPAmj明朝の版を上げる |
| 内部の仕組みの変更 | MINOR か PATCH | `src/data/` の JSON の形を変える（利用者に見えないなら PATCH でもよい） |
| 不具合の修正、同じ版の元データのままでのデータの修正 | PATCH | 作り直しのスクリプトの誤りを直して、データを作り直す |
| 呼び名・混同しやすい字の辞書（手作業）の追加・修正 | PATCH（大きく増やしたときは MINOR） | |
| ドキュメントだけの変更 | 版を上げなくてよい（次の版にまとめる） | |

### 元データを更新するとき

- 元データの側で字形が消えたり、MJ文字図形名の対応が変わったりすることがあります。この場合でも、URL の形（`#q=MJ…`）は互換を保っているので、**MINOR** とします。ただし、その URL で出てくる字が変わるので、CHANGELOG の「データ」に、消えた・変わった字形を書きます。
- 版を上げた元データとその件数の変化は、PR と CHANGELOG の「データ」に書きます（[ARCHITECTURE.md](ARCHITECTURE.md) の「データパイプライン」）。
